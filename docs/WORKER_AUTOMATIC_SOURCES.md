# 接続相手の表示と動画の自動読み取り

QNAP・Linuxを両側承認で接続すると、**設定画面内だけ**に接続相手の概要を表示します。メニューバー直下には常設の接続情報を表示しません。
QNAP側はワーカー名・URL・版数・接続状態・変換可否、Linux側は親QNAP名・URL・版数・
接続状態・共有動画フォルダ名を表示します。親情報は再起動後も残り、実際の接続状態は
10秒ごとの署名付き通信で更新します。35秒以上更新がなければオフライン表示になります。

## 手動マウントなしの動画変換

両側にこの機能を導入している場合、QNAPの動画ライブラリの登録内容が認証済みLinuxへ
自動で通知されます。変換要求時に対象動画だけの期限付きURLを発行し、LinuxのFFmpegが
HTTP Rangeで必要な範囲を直接読み込みます。全動画のダウンロードやSMB/NFSのマウント、
共有ユーザーの資格情報入力は不要です。元動画はQNAPに残り、Linuxから変更できません。

新規の両側承認接続では「Linux高速変換を使用」を有効にします。既存の接続でこの設定を
無効にしている場合は、その選択を維持します。有効化すると自動読み取りを使用します。
既存の読み取り専用マウント経路も引き続き使用できます。

動画URLは現在接続しているワーカーと対象動画に限定し、24時間で失効します。
要求ごとに現在のライブラリ登録、ファイルのサイズと更新日時、実際の接続元を検証します。
設定無効化・接続解除・フォルダ登録解除後は既存URLでも読み取れません。
ワーカーも、署名付き通信で確認した親のURL・共有ルートと一致する動画だけを読み込みます。

## 1080p (ext)

QNAPで利用可能なLinuxワーカーがあると、画質選択に `1080p (ext)` が追加されます。
設定の最大解像度・PC品質・モバイル品質にも指定でき、再生表示にLinuxワーカーの処理と
明記します。fMP4とモバイルHLSの両方に対応します。

この画質はワーカー専用です。停止・切断・変換失敗の場合はエラーとして通知し、QNAPで
1080p変換を開始しません。720p以下を選ぶと従来のQNAPへの切り替えを利用できます。
原版の直接配信は引き続きQNAPが担当します。

## 検証

- 親・ワーカーを別プロセスで起動し、マウント設定なしで1080p動画を読み込み、
  fMP4とHLSセグメントがLinuxで生成されることを確認。
- ワーカー終了後の外部1080p要求が503となり、親で変換を開始しないことを確認。
- Chromiumで両側の**設定画面**にある接続概要、Linuxの共有動画フォルダ表示、QNAPの
  `1080p (ext)` 選択と再生表示を確認。
- QNAP実機、iPad/Safariでの確認は未実施。
