# 巻をまたぐ画像キャッシュの混在防止

## 原因

巻移動ではセッションIDを維持する。一方、原寸配信の画像URLには巻IDがなく、同じページ番号が同じURLになっていた。画像レスポンスは24時間キャッシュ可能だったため、次巻の同じページ番号で前巻の画像が再利用され得た。

## 修正

- 原寸・分割・変換配信すべてでURLにentry（巻ID）を含める。
- 先読みの保持領域もセッションIDと巻IDで分離し、巻移動でリセットする。
- 画像を読み出す対象の確定と同じエンジンロック内でentryを照合する。巻移動後の古い要求は404とし、別巻の画像を旧URLへ保存しない。
- 巻IDを持たない旧URLとサムネイルは毎回再検証する。巻ID付き画像のキャッシュは維持する。

旧URLで既にブラウザに保存された画像は消去不要。修正版では別のURLになるため再利用されない。回帰テストは原寸・変換の両方で巻移動後の旧要求拒否とETagの分離を検証する。
