# 漫画一覧の評価優先表示

## 現状と目的

従来の「評価あり／評価なし」は一覧から項目を除外するフィルターだった。高評価の作品を上で見つけつつ、未評価の作品も同じ一覧で探せるようにする。

## 表示規則

- 評価欄は「ソートなし（通常順）」を既定とし、「評価優先」を選べる。モバイルもデスクトップと同じ選択肢を使う。
- 通常順では既存の並び替え（更新日時・名前・評価）とフォルダ優先を維持する。
- 評価優先ではフォルダ・漫画ファイルをまとめて星5、4、3、2、1、未評価の順に表示する。未評価は除外しない。同じ評価の項目は通常の並び替えを維持する。
- 評価変更後は一覧を再取得して並びを反映する。検索は既存どおり検索結果内を並べ替える。
- APIでは旧クライアント向けの `filter=rated` と `filter=unrated` は維持する。新しいUIからは使わない。保存済みの旧フィルター設定は選択肢がなくなるため通常順に戻る。

## 実装位置と負荷

既存のフォルダ一覧取得と通常の並び替えの後に、Pythonの安定ソートを一度行う。追加のファイル読み込みやDB検索は行わない。星数は一覧取得時にファイル・フォルダ名から既に得ている値を使う。
